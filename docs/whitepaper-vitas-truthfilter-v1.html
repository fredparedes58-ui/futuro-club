Abstract

Talent identification (TID) in youth football is systematically biased by two independent but interacting factors: biological maturation status (Peak Height Velocity, PHV) and the Relative Age Effect (RAE). Early-maturing and early-born players are consistently overrepresented in elite academies, while late-maturing players with equivalent or superior long-term potential are disproportionately deselected. Despite decades of research documenting these biases, no commercial platform currently adjusts individual performance scores by maturation status in real time.

This paper presents TruthFilter, a four-case correction framework that adjusts the VITAS Scouting Index (VSI) based on each player's PHV offset and birth quartile. We also introduce the Unified Bias Index (UBI), a composite metric that quantifies combined RAE and PHV bias on a 0–1 scale, enabling scouts and coaches to estimate how much a player's observed performance deviates from their true potential. The framework is fully deterministic, runs in under 5 ms, and is implemented in the VITAS platform as an open, transparent correction layer with per-metric confidence scores.

We describe the mathematical formulation, implementation architecture, four correction cases with their evidence base, and propose a validation protocol using retrospective academy data. This is a framework paper; empirical validation with longitudinal cohort data is the planned next step.

Keywords: talent identification, biological maturation, Peak Height Velocity, Relative Age Effect, youth football, bias correction, scouting, PHV, machine learning, sports analytics

1. Introduction

The identification and development of talented youth football players is a critical function of professional academies worldwide, with clubs investing millions annually in scouting infrastructure. Yet the process remains fundamentally flawed: systematic biases related to biological maturation and relative age consistently distort evaluations, leading to the premature deselection of players with high long-term potential.

Two well-documented biases drive this problem:

Biological maturation bias. At any given chronological age between 11 and 16, players can differ by up to 4 years in biological maturity (Malina et al., 2015). Early-maturing players are taller, heavier, faster, and stronger than their late-maturing peers — advantages that are transient but decisive during selection windows. Figueiredo et al. (2010) demonstrated that maturity status significantly influences sprint, agility, and endurance performance in U13–U15 players. Hill et al. (2021) found maturity offset correlated with sprint performance at r = 0.62–0.69, exceeding the predictive power of relative age alone.

Relative Age Effect (RAE). Players born in the first quarter after the selection cutoff date (typically January in UEFA competitions) are overrepresented in elite academies by a factor of 2–3× relative to those born in the fourth quarter (Cobley et al., 2009; Helsen et al., 2005). This bias acts as a systemic filter: Q4 players are deselected before they can demonstrate their talent, creating a cumulative dropout effect observable from age 6.

Critically, these biases interact. A late-maturing player born in Q4 faces a double disadvantage — up to 3 years of biological maturity difference plus 11 months of chronological age difference compared to an early-maturing Q1 peer in the same age group. Yet recent evidence suggests these doubly-disadvantaged players may have the highest long-term ceiling: Pereira et al. (2025) found that late maturers were more likely to compete in Top 5 European leagues as adults, and Johnson et al. (2019) showed that late-maturing academy players who survive selection become more likely to reach professional level.

Several interventions have been proposed. Bio-banding — grouping players by maturity status rather than chronological age — has shown promise in competition settings (Cumming et al., 2017). Player-labelling approaches that surface maturity information alongside performance data have been shown to reduce evaluator bias (Mann & van Ginneken, 2017; Patel et al., 2022). However, no intervention to date has implemented automated, continuous correction of individual performance scores by maturation status within a scouting platform.

This paper addresses that gap. We present TruthFilter, a framework that:

  1. Computes each player's maturation offset using the Mirwald equation (Mirwald et al., 2002) and Moore simplified variant (Moore et al., 2015);
  2. Quantifies combined RAE + PHV bias via a novel Unified Bias Index (UBI);
  3. Applies one of four correction cases to adjust the composite scouting score (VSI) in real time;
  4. Exposes correction magnitude, case rationale, and confidence score transparently to the end user.

2. Background and Related Work

2.1 Maturity Assessment Methods

The gold standard for maturity assessment is skeletal age via hand-wrist X-ray (Greulich-Pyle or TW3 method), but its cost, radiation exposure, and logistical burden make it impractical for routine academy use. Non-invasive alternatives estimate maturity from anthropometric measurements:

  • Mirwald equation (Mirwald et al., 2002): Predicts years from Peak Height Velocity (PHV) using chronological age, height, sitting height, leg length, and weight. Over 1,000 citations. Standard error ±0.59 years for males.
  • Moore simplified equation (Moore et al., 2015): Reduces required measurements while maintaining acceptable accuracy for ages 9–14.
  • Khamis-Roche method: Predicts adult height using current height, weight, and mid-parent height. Used by some professional setups (including Kitman Labs) for percentage-of-adult-height calculations.

Salter et al. (2025) recently cautioned that the Mirwald equation misclassifies 33–50% of players near PHV when used for individual-level grouping, recommending it as one input among several rather than the sole classifier. TruthFilter addresses this by incorporating confidence scores that degrade when inputs are estimated rather than measured.

2.2 Maturation and Performance

The relationship between maturation and performance is well-established but dimension-specific. Huertas et al. (2024) showed that sprinting and change-of-direction are most affected by maturation status, while jumping is less impacted. Hill et al. (2021) found maturity offset explained more variance in 5m, 10m, and 20m sprint than relative age. This implies that correction models should weight physical dimensions more heavily than technical dimensions — a principle TruthFilter implements.

2.3 Existing Interventions

Bio-banding (Cumming et al., 2017) groups players by maturity status for competition. Player-labelling (Mann & van Ginneken, 2017; Patel et al., 2022) informs scouts of maturity status during evaluation. Both approaches modify the evaluation context but leave the performance scores unchanged. No published system or commercial platform applies automatic, continuous score correction by maturation status. A 2026 systematic review in Frontiers in Psychology explicitly calls for technology-enabled maturity adjustment in TID systems but references no existing product.

2.4 Commercial Landscape

Kitman Labs ($82.3M funded, 700+ organizations) tracks PHV via Mirwald and Khamis-Roche data for 3,000+ Premier League academy players. However, their platform displays maturation data alongside performance without adjusting performance scores. Hudl ($230M), Veo ($115M), and AiSCOUT (~$21M, acquired by HUMAIN) offer video analysis and scouting tools but do not incorporate maturation correction. No platform in the market combines PHV assessment with automatic performance score adjustment.

3. The VITAS Scouting Index (VSI)

The VSI is a composite talent score on a 0–100 scale, computed as a weighted sum of five subdimensions:

VSI = 0.30 · Technique + 0.25 · Physical + 0.20 · Mental + 0.15 · Tactical + 0.10 · Projection

Each subdimension is scored 0–100 from the following data sources:

VSI subdimension definitions and data sources.
SubdimensionWeightData Sources
Technique0.30MMPose biomechanics: ball control, dribble, passing form, shooting technique
Physical0.25Sprint speed, stride frequency, bilateral asymmetry, vertical jump estimate
Mental0.20Decision latency, persistence under pressure (pose pattern proxies)
Tactical0.15Positioning, off-ball movement, spatial awareness, head scan rate
Projection0.10PHV-adjusted biological age, historical trend, development trajectory

The weighting prioritizes Technique (0.30) because technical skills are the most maturation-resistant dimension — a late maturer's first touch does not degrade by being physically smaller. Physical receives the second-highest weight (0.25) but is the dimension most susceptible to maturation bias, which is precisely what TruthFilter corrects.

VSI scores map to four tiers:

VSI tier classification.
TierRangeInterpretation
Elite85–100Top-tier talent, professional trajectory
Pro70–84Strong potential, competitive level
Talent50–69Developing, needs targeted intervention
Develop0–49Foundational stage

The VSI is fully deterministic, computed in under 2 ms, and exposes the contribution of each subdimension to the total score. This transparency is critical: scouts can see why a player received their score, not just the number.

4. PHV Maturity Offset Calculation

TruthFilter begins with computing the maturity offset — the number of years a player is from their estimated Peak Height Velocity. VITAS implements the Mirwald equation (2002) for males and the Moore variant (2015) for females.

4.1 Male Formula (Mirwald et al., 2002)

MO = −9.236 + 0.0002708 × (LL × SH) − 0.001663 × (Age × LL) + 0.007216 × (Age × SH) + 0.02292 × (W/H × 100)

Where MO = maturity offset (years from PHV), LL = leg length (cm), SH = sitting height (cm), Age = chronological age (years), W = weight (kg), H = standing height (cm).

4.2 Female Formula (Moore et al., 2015)

MO = −9.376 + 0.0001882 × (LL × SH) + 0.0022 × (Age × LL) + 0.005841 × (Age × SH) − 0.002658 × (Age × W) + 0.07693 × (W/H × 100)

4.3 Input Estimation and Confidence

When sitting height and leg length are not available (common in grassroots settings where professional anthropometric assessment is unavailable), VITAS estimates them from standing height:

SHest = H × 0.52     LLest = H × 0.48

These ratios are population averages for adolescent males (Pheasant & Haslegrave, 2005). The estimation introduces additional error, which TruthFilter accounts for by adjusting the confidence score:

5. Relative Age Effect (RAE) Quantification

The RAE module computes each player's position within their age cohort relative to the competition cutoff date (default: January 1, per FIFA regulations).

relativeMonths = (birthMonth − cutoffMonth + 12) mod 12
raeBiasFactor = 1 + (11 − relativeMonths) × 0.02

Players are assigned to quartiles (Q1–Q4) based on their relative position. The bias factor ranges from ~1.22 (Q1, maximum relative age advantage) to 1.00 (Q4, no age advantage). VSI correction for RAE alone ranges from −2 points (Q1) to +5 points (Q4).

QuartileMonths After CutoffBias FactorVSI Correction

Q2 (mid-early)3–5~1.140
Q3 (mid-late)6–8~1.08+2
Q4 (late cohort)9–11~1.00+5

6. The Unified Bias Index (UBI)

The UBI is a novel composite metric that quantifies the combined impact of RAE and PHV bias on a single 0–1 scale. To our knowledge, no prior work has formalized the combination of these two biases into a single actionable index.

6.1 Formulation

raeComponent = (birthQuartile − 1) / 3
phvComponent = clamp(−phvOffset / 2,   0,   1)    [for late maturers]
phvComponent = clamp(phvOffset / 2,   0,   0.5)    [for early maturers]
UBI = 0.55 × raeComponent + 0.45 × phvComponent
VSIcorrectionFactor = 1 + UBI × 0.12

6.2 Weight Justification (0.55 RAE / 0.45 PHV)

RAE receives greater weight (0.55) because it represents a systemic selection bias: Q4 players are deselected before demonstrating their talent, creating a cumulative dropout effect (Cobley et al., 2009). Helsen et al. (2005) showed that RAE persists even after controlling for maturation. RAE acts as a filter at the point of selection, while PHV bias primarily affects performance assessment once a player is already observed.

PHV receives lower weight (0.45) because it is a temporal performance bias: maturation differences converge by ages 17–18 (Malina et al., 2004). A late maturer who survives selection has high probability of reaching or exceeding early-maturer performance post-maturation. The bias is self-correcting given sufficient time; RAE is not.

6.3 Correction Cap

The maximum VSI correction factor is 1.12 (i.e., +12%). This cap is deliberately conservative: some studies suggest Q4 late maturers may be underestimated by 15–20%, but we prefer moderate adjustment to avoid overcompensation. The cap can be adjusted per competition level in future versions as validation data becomes available.

6.4 Interpretation Scale

0.40–0.69Moderate biasConsider bias when evaluating VSI.
0.20–0.39Low biasMinor impact on evaluation.

7. TruthFilter: Four-Case Correction Model

TruthFilter applies one of four correction cases based on the player's combined PHV and RAE profile. Each case has a specific correction range, confidence level, and evidence base.

7.1 Case 1: Early Maturers (phvOffset > +0.5)

ParameterValue
VSI correction−3 to −8 points
Formuladelta = −min(8, round(phvOffset × 4))
Confidence (real PHV data)0.85
Confidence (estimated)0.60

Rationale. Early maturers benefit from transient physical advantages — greater height, mass, speed, and strength relative to chronologically-same-age peers. This inflates performance in Physical subdimension metrics. Meylan et al. (2010) showed that approximately 70% of the sprint advantage of early maturers disappears when controlling for biological age. TruthFilter discounts the observed VSI to approximate what the player's score would be without the maturation advantage, providing a more accurate estimate of long-term potential.

7.2 Case 2: Late Maturers (phvOffset < −0.5)

ParameterValue
VSI correction+3 to +10 points
Formuladelta = +min(10, round(|phvOffset| × 4))
Confidence (real PHV data)0.88
Confidence (estimated)0.65

Rationale. Late maturers are systematically underestimated because they compete against peers with up to 2+ years of biological maturity advantage. Their technical and tactical quality is masked by physical disadvantage. Deprez et al. (2015) demonstrated that late maturers who survive selection have greater probability of reaching professional level. The asymmetric range (+10 vs. −8) is intentional: the cost of discarding a talented late maturer (false negative) is higher than the cost of slightly overestimating an early maturer (false positive).

Design decision: The asymmetric correction range (+10/−8) reflects a deliberate ethical choice. In talent identification, false negatives (missing real talent) are more costly than false positives (advancing a player who doesn't make it). A player who is advanced but doesn't succeed still benefits from the development experience. A player who is deselected due to maturation bias never gets the chance.

7.3 Case 3: On-Time + High RAE (Q1/Q2, normal maturation)

ParameterValue
VSI correction−1 to −3 points
FormulaQ1: −3, Q2: −1
Confidence0.70

Rationale. No PHV bias but RAE advantage. A Q1 player born in January has up to 11 months more development than a Q4 player born in December of the same selection year. In U12–U14 categories, this translates to measurable advantages in accumulated training hours, physical development, and competitive experience.

7.4 Case 4: On-Time + Low RAE (Q3/Q4, normal maturation)

ParameterValue
VSI correction+1 to +4 points
FormulaQ4: +4, Q3: +1
Confidence0.72

Rationale. No PHV bias but RAE disadvantage. These players compete with up to 11 months less development. A moderate upward correction acknowledges this chronological disadvantage.

8. Implementation Architecture

TruthFilter is implemented as a deterministic pipeline in the VITAS platform, deployed as Vercel Edge Functions with sub-5ms latency. No machine learning model or LLM is used in the correction pipeline itself — the system is pure arithmetic, guaranteeing reproducibility and auditability.

8.1 Pipeline

Input: { age, height, sittingHeight?, legLength?, weight, gender, birthMonth, currentVSI }
  │
  ├──→ PHV Calculator (Mirwald/Moore)  →  { offset, category, confidence }
  │
  ├──→ RAE Service                     →  { quartile, biasFactor }
  │
  ├──→ UBI Service (PHV + RAE)         →  { ubi, correctionFactor }
  │
  └──→ TruthFilter (4-case switch)     →  { adjustedVSI, delta, confidence, explanation }

Output: { originalVSI, adjustedVSI, delta, ubi, filterCase, confidence, explanation }

Total latency: < 5ms · Cost per computation: €0 · Deterministic: yes

8.2 Transparency Design

A core design principle is that every correction is visible and explainable. The VITAS interface displays:

  • Original VSI alongside adjusted VSI, with a color-coded delta indicator;
  • The TruthFilter case that was applied, with natural-language explanation;
  • Confidence score (0–1) reflecting input quality;
  • UBI value with breakdown of RAE and PHV components;
  • Whether anthropometric inputs were measured or estimated.

This transparency allows coaches and scouts to understand the correction rather than blindly trusting it — a critical feature for adoption in a domain where practitioners have deep domain expertise and rightfully resist black-box systems.

9. Limitations and Honest Assessment

Transparency note. This section intentionally identifies the framework's current limitations. We believe honest disclosure strengthens rather than weakens the contribution.
  1. No longitudinal validation. The correction magnitudes are derived from published literature, not from validation against a prospective cohort. The framework needs testing with real academy data (target: N ≥ 30 players across 2+ seasons) to verify that TruthFilter-adjusted VSI predicts long-term outcomes better than raw VSI.
  2. Mirwald equation accuracy. Salter et al. (2025) showed the Mirwald equation misclassifies 33–50% of players near PHV for individual-level maturity grouping. TruthFilter mitigates this by using maturity offset as a continuous variable (not a binary classifier) and by degrading confidence scores when inputs are estimated.
  3. Correction magnitudes are heuristic. The ×4 multiplier and caps (−8/+10) are informed by literature but not empirically optimized. With sufficient data, these could be replaced by coefficients estimated from logistic regression on career outcomes.
  4. UBI weights are assumption-based. The 0.55/0.45 RAE/PHV split is justified by the literature review but could be refined with competition-specific data. Different leagues with different cutoff dates may require different weightings.
  5. Sample size. The VITAS platform currently operates with 3 demo players and ~290 seeded professional profiles. No real academy youth data has been processed through TruthFilter at the time of publication.
  6. Input quality dependency. When parents enter height data from home rather than a professional measuring sitting height and leg length, the PHV estimate degrades. The confidence system signals this but cannot prevent errors in self-reported data.

10. Proposed Validation Protocol

We propose a three-phase validation strategy:

Phase A: Retrospective Academy Analysis (N ≥ 50)

  • Partner with 1–2 youth academies that have historical anthropometric and performance data
  • Compute TruthFilter-adjusted VSI retrospectively for players aged 12–15 at time of measurement
  • Compare adjusted VSI vs. raw VSI as a predictor of which players reached U18/U21/professional level
  • Hypothesis: Adjusted VSI has higher AUC-ROC for predicting professional progression

Phase B: Prospective Cohort (N ≥ 100, 2 seasons)

  • Enroll 100+ youth players (ages 11–15) with quarterly anthropometric measurements
  • Track both raw and TruthFilter-adjusted VSI over 2 seasons
  • Measure outcomes: progression to next age group, squad selection, professional contract
  • Use the data to empirically optimize correction coefficients

Phase C: Multi-Club Comparative (N ≥ 500)

  • Deploy TruthFilter across multiple academies in different countries
  • Compare scouting decisions with vs. without TruthFilter
  • Measure changes in: Q4 retention rate, late maturer retention, long-term hit rate

11. Conclusion

TruthFilter represents the first formalized, implemented framework for automatically correcting youth football scouting scores by biological maturation status and relative age. The Unified Bias Index (UBI) provides a single, interpretable metric for quantifying combined bias — a construct that, to our knowledge, has not been previously formalized in the literature.

We make no claim that TruthFilter is a validated predictive model. It is, at this stage, a principled correction framework grounded in two decades of maturation research. Its value lies in making bias visible and actionable — converting decades of academic findings into a real-time tool that coaches and scouts can use at the point of decision.

The framework is open and transparent: every correction is explainable, every confidence score reflects input quality, and every formula is documented in this paper. We invite collaboration with academies, researchers, and sports scientists to validate and refine TruthFilter with real-world longitudinal data.

The children who are deselected at 13 because they matured late deserve better than a system that confuses size with talent.

Appendix A: Complete TruthFilter Implementation (TypeScript)

// TruthFilter — 4 cases
export const TruthFilterService = {
  detectCase(phvOffset, phvCategory, raeResult) {
    if (phvCategory === "early" || phvOffset > 0.5)  return "early_maturers";
    if (phvCategory === "late"  || phvOffset < -0.5)  return "late_maturers";
    if (raeResult && raeResult.birthQuartile <= 2)     return "ontime_high_rae";
    return "ontime_low_rae";
  },

  apply(vsi, phvOffset, phvCategory, raeResult) {
    const filterCase = this.detectCase(phvOffset, phvCategory, raeResult);
    let delta = 0, confidence = 0.7;

    switch (filterCase) {
      case "early_maturers":
        delta = -(phvOffset ? Math.min(8, Math.round(phvOffset * 4)) : 3);
        confidence = phvOffset ? 0.85 : 0.60;
        break;
      case "late_maturers":
        delta = +(phvOffset ? Math.min(10, Math.round(Math.abs(phvOffset) * 4)) : 4);
        confidence = phvOffset ? 0.88 : 0.65;
        break;
      case "ontime_high_rae":
        delta = -(raeResult?.birthQuartile === 1 ? 3 : 1);
        confidence = 0.70;
        break;
      case "ontime_low_rae":
        delta = +(raeResult?.birthQuartile === 4 ? 4 : 1);
        confidence = 0.72;
        break;
    }
    return {
      filterCase, originalVSI: vsi,
      adjustedVSI: Math.min(100, Math.max(0, vsi + delta)),
      delta, confidence
    };
  }
};

// UBI — Unified Bias Index
export const UBIService = {
  calculate(raeResult, phvOffset, phvCategory) {
    const raeComp = raeResult ? (raeResult.birthQuartile - 1) / 3 : 0;
    let phvComp = 0;
    if (phvCategory === "late")  phvComp = Math.min(1, Math.max(0, -phvOffset / 2));
    if (phvCategory === "early") phvComp = Math.min(0.5, Math.max(0, phvOffset / 2));

    const ubi = 0.55 * raeComp + 0.45 * phvComp;
    return { ubi, raeComponent: raeComp, phvComponent: phvComp,
             correctionFactor: 1 + ubi * 0.12 };
  }
};
